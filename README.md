# Gestor de Tareas Ágiles (CRUD con IA)

Aplicación web sencilla desarrollada para el seminario de **Gestión de Software Ágil asistido por Inteligencia Artificial**. Permite administrar tareas de un equipo mediante las operaciones básicas CRUD con persistencia local.

## Enlaces del Proyecto
- **Video explicativo:** https://youtu.be/UnZzG6-v5ZE?si=4wjNBbTjhH3c3Y86

##  Tecnologías Utilizadas
- **HTML5:** Estructura semántica de la aplicación.
- **CSS3:** Estilos modernos, variables CSS y diseño responsivo.
- **JavaScript (ES6+):** Lógica del CRUD, manipulación del DOM y eventos.
- **LocalStorage:** Persistencia de datos en el navegador sin necesidad de backend.

- ##  Enlace para Ejecutar: https://juanfediaz.github.io/CRUD/

##  Pront 1:
Actúa como un desarrollador frontend senior. Crea una aplicación web CRUD en un solo archivo HTML (con CSS y JS integrados) para gestionar tareas/proyectos ágiles. Debe permitir crear, leer, actualizar y eliminar registros (Título, Responsable, Estado: Pendiente/En Progreso/Completado). Usa localStorage para persistir los datos y un diseño limpio y moderno."
Para qué sirve: Genera la primera versión funcional del sistema para probar que el CRUD y el almacenamiento local operan correctamente.

##  Pront 2:
Refactoriza el código anterior separándolo en tres archivos profesionales: index.html, styles.css y app.js. Mejora la experiencia de usuario agregando validación de formularios (no permitir campos vacíos), un mensaje de confirmación antes de eliminar un registro y un botón para cancelar la edición."
Para qué sirve: Demuestra buenas prácticas de ingeniería de software (modularidad) y mejora la robustez de la interfaz.

##  Pront 3:
Agrega un buscador en tiempo real por título o responsable y etiquetas de colores (badges) según el estado de la tarea en styles.css y app.js."
Para qué sirve: Muestra cómo la IA permite añadir valor ágilmente mediante iteraciones cortas.
